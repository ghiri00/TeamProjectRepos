Console RPG Survival
---

Це консольна рольова гра з елементами виживання, де головним ворогом гравця є монстри.

## 🌟 Основна ідея

Гравець має вижити якомога довше, прокачуючи стати у битвах. Кожна дія наближає персонажа до його цілі, що безпосередньо впливає на його бойові характеристики.

## 👤 Персонаж та Характеристики

Існує 3 раси:
1. Люди
2. Ельфи
3. Дварфи
---

Здоров'я (HP): Якщо впаде до 0 — гра закінчена.

Втома (Fatigue): Шкала від 0 до 150.
